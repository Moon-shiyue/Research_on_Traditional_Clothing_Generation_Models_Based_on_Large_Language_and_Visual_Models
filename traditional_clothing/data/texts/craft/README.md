# 传统服饰工艺规范

## 裁剪工艺
- **右衽原则**: 汉族服饰始终右衽（左襟压右襟），左衽为死者/异族之服
- **交领交叉角度**: 通常35-55度，形成自然的Y形领口
- **马面裙马面宽**: ≥15cm，通常20-35cm（明代较宽，清代稍窄）
- **褶裥规则**: 马面裙褶裥成对出现（偶数），通常4-8对
- **琵琶袖特征**: 袖口窄(12-16cm) → 袖身膨胀(30-40cm) → 袖根中等(20-25cm)

## 缝制工艺
- **滚边工艺**: 领口、袖口、下摆等多用滚边(包边)装饰
- **盘扣**: 明清时期对襟服饰的标志性闭合方式
- **系带**: 汉唐至明，襦裙、深衣多用系带而非纽扣
- **缝份**: 传统手工缝份通常0.8-1.5cm

## 面料类型
- **锦**: 彩色提花丝织物，唐代最盛（蜀锦、云锦、宋锦）
- **缎**: 缎纹组织，光泽好，明清官服常用
- **罗**: 绞经组织，轻薄透气，宋代女装最常用
- **纱**: 平纹薄型，夏日衣料，马王堆素纱禅衣仅49g
- **绢**: 平纹丝织物，最为常见的基础面料
- **缂丝**: 通经断纬，最为名贵，明清皇家用
- **妆花**: 多彩挖花，明代最精（云锦妆花）

## 色彩等级体系
- **明黄/赭黄**: 皇帝专用（唐→清）
- **大红**: 品官公服，婚服
- **紫色**: 唐为三品以上，宋后放宽
- **青色/蓝色**: 士庶常用
- **白色**: 丧服/素服（宋文人例外）
- **黑色**: 秦代尊崇，后世多为皂隶之服
