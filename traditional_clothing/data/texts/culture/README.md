# 传统服饰文化背景

## 各朝代服饰特征概要

### 汉代 (前206 - 220)
- **主要形制**: 曲裾深衣、直裾深衣
- **特征**: 交领右衽、宽袖、衣襟绕体多层
- **代表**: 马王堆汉墓出土丝织品
- **色彩**: 朱红为尊，玄（黑）为贵

### 魏晋南北朝 (220 - 589)
- **主要形制**: 襦裙、杂裾垂髾服
- **特征**: 宽衣博带，飘逸风骨
- **代表**: 《女史箴图》《洛神赋图》
- **影响**: 佛教传入带来西域纹样

### 唐代 (618 - 907)
- **主要形制**: 齐胸襦裙、圆领袍、大袖衫
- **特征**: 高腰齐胸、广袖飘逸、色彩艳丽、坦领开放
- **代表**: 《簪花仕女图》《捣练图》
- **影响**: 丝绸之路带来胡风（联珠纹、翻领等）
- **特色**: 女着男装、袒领、披帛

### 宋代 (960 - 1279)
- **主要形制**: 褙子、对襟衫、百迭裙
- **特征**: 清雅含蓄、窄袖实用、淡雅色调
- **代表**: 《清明上河图》《瑶台步月图》
- **特色**: 褙子成为女装标志、理学影响下的保守含蓄

### 明代 (1368 - 1644)
- **主要形制**: 袄裙、马面裙、圆领袍、道袍
- **特征**: 立领兴起、琵琶袖、马面裙（⭐核心）
- **代表**: 定陵出土服饰、孔府旧藏
- **特色**: 恢复汉族传统、立领琵琶袖为明代标志

### 清代 (1644 - 1912)
- **主要形制**: 旗装、氅衣、衬衣、马面裙（延续）
- **特征**: 立领高耸、箭袖、滚边繁多
- **代表**: 故宫博物院藏清代宫廷服饰
- **特色**: 满汉融合、等级制度森严（补服、花翎）

## 礼制规范
- **五服制度**: 斩衰、齐衰、大功、小功、缌麻（丧服等级）
- **冕服制度**: 十二章纹（帝王最隆重礼服）
- **品色制度**: 唐代起以颜色区分官品等级
- **补服制度**: 明清以补子纹样区分文武品级

## 非遗技艺
- **云锦**: 南京，世界非遗，寸锦寸金
- **宋锦**: 苏州，与云锦、蜀锦并称三大名锦
- **苏绣**: 苏州，四大名绣之首
- **湘绣**: 湖南，以狮虎见长
- **粤绣**: 广东，金银线垫绣
- **蜀绣**: 四川，以软缎和彩丝为主
- **缂丝**: 苏州，通经断纬，最名贵丝织品
- **香云纱**: 广东，薯莨染整的真丝面料
