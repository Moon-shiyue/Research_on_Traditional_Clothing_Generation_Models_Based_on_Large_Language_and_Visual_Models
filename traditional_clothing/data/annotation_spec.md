# 传统服饰数据标注规范（Annotation Specification）

> 版本 1.0 ｜ 维护：申新卓 ｜ 适用于 `dataset_index.json` 与 `data/annotations/` 下全部标注数据

本规范定义传统服饰数据的 **四级结构化标注** 体系：

```
朝代 → 形制 → 部件 → 纹样
```

目标是让每条数据既能支撑大语言模型的文本训练（知识编码），
也能支撑视觉模型的图像理解（部件/纹样识别）。

---

## 1. 标注层级

| 层级 | 字段 | 说明 | 示例 |
|------|------|------|------|
| L1 朝代 | `dynasty` | 所属历史朝代 | 明 / 唐 / 宋 / 汉 / 清 / 魏晋 |
| L2 形制 | `garment_type` | 服装整体形制类型 | 袄裙、圆领袍、马面裙、褙子裙 |
| L3 部件 | `components` | 领 / 袖 / 下裳的部件标注 | collar=立领, sleeve=琵琶袖, skirt=马面裙 |
| L4 纹样 | `patterns` | 装饰纹样（可多项） | 缠枝莲纹、如意云纹 |

---

## 2. 服装条目字段

每条服装标注（`data_type: "reference_knowledge"`）必须包含：

```json
{
  "image_id": "knowledge_ming_aoqun_001",
  "dynasty": "明",
  "era_detail": "万历年间",
  "garment_type": "袄裙",
  "components": {
    "collar": "立领",
    "sleeve": "琵琶袖",
    "skirt": "马面裙"
  },
  "patterns": ["缠枝莲纹", "如意云纹"],
  "colors": ["藏蓝", "银白", "金"],
  "material": "织金妆花缎",
  "ceremony_level": "常服",
  "social_status": "士庶命妇",
  "source": "山东博物馆藏",
  "description": "……形制描述，用于 LLM 训练文本……",
  "annotator": "申新卓（知识编码）",
  "review_status": "knowledge_verified",
  "data_type": "reference_knowledge"
}
```

### 字段约束

| 字段 | 必填 | 取值约束 |
|------|------|----------|
| `image_id` | ✅ | 全局唯一，`knowledge_<朝代>_<形制>_<序号>` |
| `dynasty` | ✅ | 汉 / 魏晋 / 唐 / 宋 / 元 / 明 / 清 |
| `era_detail` | ✅ | 具体年号或时期，如"万历年间" |
| `garment_type` | ✅ | 见附录 A 形制词表 |
| `components.collar` | ⭕ | 交领 / 圆领 / 立领 / 对襟 / 直领对襟 / 坦领 / 无 |
| `components.sleeve` | ⭕ | 广袖 / 窄袖 / 琵琶袖 / 箭袖 / 大袖 / 宽袖 / 无袖 |
| `components.skirt` | ⭕ | 马面裙 / 襦裙 / 齐胸襦裙 / 百迭裙 / 间色裙 / 袍服 / 无 |
| `patterns` | ⭕ | 见附录 B 纹样词表，可多项 |
| `colors` | ✅ | 服饰主色，2~4 项 |
| `material` | ✅ | 面料材质，如织金妆花缎 / 缂丝 / 罗 / 绢 |
| `ceremony_level` | ✅ | 朝服 / 礼服 / 常服 / 便服 |
| `social_status` | ✅ | 皇帝 / 贵族 / 命妇 / 士人 / 士庶 / 旗人女眷 |
| `source` | ✅ | 馆藏/出土/文献出处 |
| `description` | ✅ | 完整形制描述（LLM 训练语料来源） |
| `annotator` | ✅ | 标注人署名 |
| `review_status` | ✅ | `knowledge_verified`（知识已验证） |

## 3. 纹样条目字段

纹样标注（`data_type: "pattern_reference"`）使用 `pattern_name` 替代 `garment_type`：

```json
{
  "image_id": "pattern_chanzhilian_019",
  "dynasty": "通用",
  "pattern_name": "缠枝莲纹",
  "pattern_era": "宋→明清",
  "description": "以莲花为主体，枝蔓缠绕连绵不断……",
  "typical_colors": ["青花蓝白", "五彩", "青绿"],
  "source": "景德镇陶瓷纹样、明清织锦纹样",
  "annotator": "申新卓（知识编码）",
  "review_status": "knowledge_verified",
  "data_type": "pattern_reference"
}
```

---

## 4. 部件词表（受控词汇）

部件标注必须使用受控词表，禁止自由描述，以保证下游组件库可映射：

- **领型**：交领、圆领、立领、对襟、直领对襟、坦领
- **袖型**：广袖、窄袖、琵琶袖、箭袖、大袖、宽袖、无袖
- **下裳**：马面裙、襦裙、齐胸襦裙、百迭裙、间色裙、曲裾绕襟、直裾、杂裾、袍服
- **配饰**：云肩、褙子、半臂、披帛、比甲

> 映射关系：词表条目 → `garment_components/` 下的组件类
> （如"琵琶袖"→ `PipaSleeve`，"马面裙"→ `MamianSkirt`）。

---

## 5. 数据质量要求

1. **来源可溯**：每条标注必须记录 `source`（馆藏/出土/文献），禁止来源不明的数据
2. **形制准确**：部件组合必须符合历史形制（如琵琶袖仅明代、清代不用琵琶袖），
   可借助 `validation/` 校验引擎自动检查
3. **描述完整**：`description` 需覆盖朝代、部件、纹样、色彩、面料、用途，
   作为 LLM 训练语料时 ≥60 字
4. **权限合规**：图像数据须来自开放许可来源（MET CC0、Wikimedia Commons、
   明确声明免费开放的博物馆数据集）
