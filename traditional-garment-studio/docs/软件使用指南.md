# 传统服饰纸样软件使用指南

当前共22类、16种两件上下装搭配，选配云肩、多层外搭和披帛后共209组合。原21类/168组合保留，新增可明确选择的直幅后背系带内搭；它不能代替吊带或闭背款。圆领、立领分对襟闭合与右斜襟；直领对襟上衣保持前中开敞。有袖整件可选直线袖/琵琶袖、独立袖口条。输入图片或文字，输出有厘米标注的二维净样；照片确认可见款式，具体尺寸由文字、人体面板和明示模板默认值决定。

## 启动与检查

在项目目录先运行 `run-backend.cmd`，再运行 `run-frontend.cmd`，保留两个终端，浏览器打开 <http://127.0.0.1:5173/>。目前是本机原型，需要相邻的 `garmentcode-traditional` 资源和已有d2g环境。

启动有问题时双击 `check-studio.cmd`，查看ERROR项。该工具只检查本机环境、资源和服务，不安装软件、不发起识图、不读取或输出登录凭据。命令行可运行 `check-studio.cmd --offline` 仅查环境；需要保存结果时用 `check-studio.cmd --json > setup-check.json`。检查通过不等于远端额度、识图质量或实体制衣已通过。

## 先设置尺寸

在“人体尺寸”填写身高、胸围、腰围等厘米数。输入数字后按回车或离开输入框提交；保存完成后再改下一项。还没有纸样时只保存体型，不会自动生成裙子。

已有纸样会按新体型重算；文字或面板明确指定的厘米衣长、裙长保持不变。若尺寸组合无法形成有效裁片，会保留旧版本并给出调整提示。

## 文字生成

可直接输入这些完整例子：

- `明代褙子，衣长110cm，袖长48cm；马面裙，裙长95cm，常服`
- `唐代半臂，衣长50cm；襦裙，裙长95cm，常服`
- `交领上衣，衣长60cm；襦裙，裙长95cm；双层云肩`
- `交领上衣，衣长55cm，袖长45cm；褙子，衣长110cm，袖长48cm；马面裙，裙长95cm；双层云肩`
- `立领对襟上衣，琵琶袖，袖长55cm，袖口条宽4cm；马面裙，裙长95cm`
- `圆领长袍，衣长130cm，袖长55cm`
- `直幅系带抹胸，围前净高30cm，围前覆盖比0.65；直领对襟上衣，衣长60cm；襦裙，裙长95cm`
- `直领对襟上衣，衣长60cm，袖长55cm；襦裙，裙长95cm`
- `交领上衣，衣长55cm；直领对襟上衣，衣长60cm；马面裙，裙长95cm；披帛，净长300cm，净幅宽30cm`
- `交领上衣，衣长55cm；圆领对襟比甲，衣长70cm，侧衩高15cm；襦裙，裙长95cm`
- `三层云肩，六个云头，无垂须`
- `琵琶袖，袖长49cm，袖口宽15cm，袖根宽22cm，膨起宽35cm`

明确长度请写单位，例如95cm、一百一十厘米；同一参数给一个确定值。范围、多个候选、排除条件会要求澄清。褙子“袖口整围”与半臂“袖口平铺半围”含义不同，面板已区分标注。局部领片、袖片只输出该局部，不会补出整件长袍。

叠穿可分别命名内层交领/圆领/立领上衣、外层褙子/半臂/圆领对襟比甲/直领对襟上衣、下裙、云肩和披帛。各件尺寸放在各自名称后，用分号分开，避免把两件袖长写在同一段。比甲当前只支持圆领对襟无袖基础款，不能替代立领、大襟或琵琶襟款。整套图缩得太小时，点纸样区“适合宽度”，滚动查看全部裁片；“查看整图”返回总览。左右仍共用厘米比例，查看缩放不改变导出尺寸。

## 图片生成

只露直上缘胸前内搭时，如果其余衣物均已确认，可点“采用直幅后背系带内搭基础款”生成完整组合；这表示你选定一种基础裁法，不是模型确认了背面。实际为吊带、闭背或曲线上缘时应补图。该选款说明会随参数修改、ZIP文字说明和恢复保留。内搭净高、系带长度为厘米；围前展开宽按人体胸围乘覆盖比计算，先设胸围，再核对右图尺寸。

1. “完整服饰识图”默认开启；仅制作独立领片、袖片等时切换局部模式。
2. 上传参考图，可以同时输入具体尺寸或明确只做哪个组件，再点“发送图片”。尽量使用前襟、裙腰、裙门和袖口清晰可见的照片。
3. 阅读可见结构与建议范围，确认后生成；整件长袍不拆成局部，组合不会丢掉其中一件。前襟被遮挡而衣身/领型明确时，可选择对襟或右斜襟基础款，参数来源标为“样式由你确认”；不把选择当作图中已经确认的结构。
   2026-10-26起也会列出整图衣物清单。不同套服饰放在一张图时先裁出一套；同款正反面可以保留。裙腰或侧褶被挡时，可选择后端提供的马面裙/襦裙下裳基础款，连同全部已确认上装生成；若开襟也待确认，会接着询问。两种选择均不会冒充图片已确认的细节。
4. 在“设计参数”修改长度、褶量、袖口等；参数下面会注明文字指定、手动设置、图片结构识别或默认来源。
   直幅披帛可与原有组合搭配；例如“交领上衣；襦裙，裙长95cm；披帛，净长300cm，净幅宽30cm”。披帛净长和幅宽直接用厘米，不随人体缩放；四边工艺余量另加。宽披肩、霞帔、圆弧或拼接披帛仍不能用直幅替代。侧衩等控件的可选范围会按当前人体和衣长更新，先阅读限制说明再调整。

云肩当前支持1–3层；能看清4层及以上时说明不支持，不会自动减少层数。整套中仍有衣物类型无法确认时，会保留整套待补充状态，不只生成领袖或裙子。识图不可用时可显式重试，不会自动切换到付费API。纯文字制作可不附图片另行发送。特殊曲裾、贴里、马蹄袖和复杂宫廷款仍须对应专用模板，基础款不能冒充精确复原。

带圆领口的宽幅扇形披领，不等于有云头起伏的云肩或窄圆领贴。当前无对应模板时会说明范围，不能用其它形状替代。

## 查看与保存

云肩可调整“云头大小基准（cm）”和“前摆延伸（cm）”。前者改变云头曲线大小，后者只加长前侧；两者均不是整件宽高。请在右侧净样或裁片清单核对总尺寸。图片中覆胸等特征只能建议默认比例，厘米值仍需按实际用途调整。明确输入厘米后，修改肩宽会保留该厘米值；恢复旧云肩时从原轮廓还原原大小，不改写旧图。

- 左侧人体为二维定位、折叠示意；右侧是无人体的完整净样。两侧共用厘米比例。用“＋”放大，或展开“裁片尺寸清单”查看每片净宽×净高。
- “本次参考图”查看当前已确认纸样对应的图片。左侧聊天中后发、未确认的图不会替换它。
- “最近纸样”恢复最近10份完整结果，同时恢复体型、款式和参考图；重启仍保留所选版本。需要长期留存请下载ZIP。
- “下载”获得SVG、几何与参数JSON、中文README及文件校验清单。参考照片不放入ZIP。新保存版本在恢复及导出前核对文件回执，损坏时保留当前可用结果并提示。
- ZIP文件名带服饰名称和版本标识，例如`二维纸样-半臂＋襦裙下裳-版本标识.zip`，方便区分多次下载的结果。
- 具有`assembly.json`的基础款，包内README同时列出中文裁布份数、直丝/斜裁提示与组装顺序，可先按清单核对裁片。
- “A4纸样”先显示分幅数量，确认再下载1:1 PDF。按100%实际大小打印，关闭“适应纸张”，先量首页10cm校准框；同一裁片相邻页按5mm重叠拼接。

默认SVG与A4 PDF都是不含缝份的净样。马面裙另有明确标注接腰、侧边与折边余量的 `cutting*.svg`，按包内README核对，勿重复加缝份。左侧人体示意不能直接用于裁布。

## 常见状态

| 看到的情况 | 含义与处理 |
| --- | --- |
| 图片建议待确认，右侧有旧纸样 | 新图还没生成；确认左侧建议后才替换 |
| 提示结构不清或不支持 | 换无遮挡照片、切换单件，或明确输入支持的组件 |
| 图片请求失败 | 查看云端视觉设置与额度，再点显式重试；旧纸样保留 |
| 参数更新被拒绝 | 当前组合尺寸不相容；按提示调整，或恢复默认 |
| 纸样重启后仍在，聊天清空 | 正常；纸样与体型保存在本机，临时识图建议不恢复 |
| 下载后需要精确尺寸 | 使用净样SVG或A4 PDF，并先核对10cm校准标记 |

这是可调整的基础版型原型。已进行平面轮廓、配缝、参数与导出一致性检查；尚未实体试缝，不承诺任意服饰照片的精确复原或完全合身。
