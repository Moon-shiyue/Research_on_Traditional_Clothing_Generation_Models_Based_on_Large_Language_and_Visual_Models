# 完整服饰纸样支持范围（2026-10-26）

默认识别完整服饰。图片中的上衣、外衣、下裙、云肩逐件解析；支持的组合一起生成，未确认或未支持的衣物不会被丢掉。仅在用户明确选择局部时生成独立领片、袖片或下裙。

原21类全部保留，新增直幅系带内搭，应用目录共22类。独立交领/圆领/立领/对襟领片以及广袖/窄袖/琵琶袖仍可明确单做。

支持209种组合：原168组保留，基础内搭配下裙、外搭和饰件新增41组。最多包含内上衣或基础内搭、外衣、下裙、云肩、披帛五件。各件分别缝制，不跨衣物缝合。

只露胸前直上缘内搭时，不能从图片认定背面裁法；在其余成员已确认且组合可用时，可明确选择直幅后背系带基础款，随结果和导出保留“用户选款”来源。吊带、闭背、心形/曲线上缘等不提供此候选。通称“抹胸”并不能自动匹配该基础款；净高默认30cm、覆盖比默认0.65，均非照片测量或文物实测。围前展开宽随胸围和覆盖比计算，系带长度受后背围裹范围限制。

直领对襟上衣用于开敞前襟的短衣身有袖基础款，不能代替闭合圆领/立领、无袖比甲、长褙子或短袖半臂。尺寸为应用参数，不是从文物裁图直接量取。直领对襟的类别参考[中国丝绸博物馆研习说明](https://www.chinasilkmuseum.com/ngcxg/info_11.aspx?itemid=31128)，短衣长与长袖组合由应用另行制版。

有袖的新整件可选直袖或连接琵琶袖，可加独立袖口条。侧衩真实拆分侧缝，下段不缝；净样标注高度与开口。比甲为完整无袖款，不能通过隐藏有袖上衣的袖片冒充。当前比甲只支持圆领对襟；不把斜襟、琵琶襟、立领无袖衣替换成这一款。

图像识别描述可见结构，人体和明示默认值决定厘米尺寸。高腰/齐胸长裙无指定长度时按穿着位置估算至近脚踝，明确厘米长度保持；比甲短/中长/长类别映射不同衣长。完整袍衫的腰部清晰无带时不附加腰带。未看清的领襟、云肩层数等不可视为照片测量。

前襟遮挡时，可选择本应用一种基础开襟；下裙仅裙门/侧褶被挡时，可在提供的支持款式中明确选择。来源标成用户选择，仍连同全部已确认衣物生成。不同人物的不同套服饰不能混合；先裁出本次的一套。

复杂曲裾、贴里腰褶、龙蟒袍、旗袍、披风、霞帔及其它未支持结构会请求补充或调整，不会只输出其中的裙子、领片或袖片。披帛仅支持直幅，不替代宽披肩、扇形、圆弧或拼接结构。默认300×30cm可调整，不是照片或文物实测；左侧展示纵向松折后的两段，肩后连接段不展开，右侧仍为一整幅净样。

左侧为二维定位与折叠示意，右侧为真实净样，统一厘米比例。长图可点“适合宽度”滚动看全部裁片；缩放不改变SVG、ZIP或A4比例。净样无缝份；马面裙另有明确标注余量的制版图。轮廓、配缝与导出通过软件检查，不等于实体试缝或文物原裁法复原。
